# Пульт – презентация

Интерактивная презентация «Пульта» – российской системы мониторинга ИТ-инфраструктуры на базе Zabbix от «Лаборатории Числитель». Рассчитана на первую встречу с заказчиком: команды эксплуатации и их руководителей.

**Открыть:** https://pinkkoff.github.io/pult-main-deck/

По основной ссылке открывается актуальная версия презентации. Ранее отправленные ссылки с `/v2/` ведут на тот же слайд по основному адресу.

## Управление

| Действие | Как |
|---|---|
| Следующий / предыдущий слайд | ← →, пробел, клик по правой или левой половине слайда, свайп |
| В начало / в конец | Home / End |
| Полный экран | F или кнопка ⤢ |
| Подсказка по клавишам | ? |
| Скачать PDF | кнопка «Скачать PDF» рядом со стрелками |

Ссылка на конкретный слайд – номер или идентификатор после `#`, например `#10` или `#roadmap`.

## Что внутри

1. Знакомство и вопросы о текущем мониторинге.
2. **Что такое Пульт:** весь цикл мониторинга, архитектура, сценарии использования.
3. **Почему Пульт:** импортозамещение и переезд с Zabbix за неделю, безопасность и 117 приказ ФСТЭК, highload, новые модули, сравнение, связка с Графиней.
4. **Доказательства и условия:** кейсы, заказчики и признание рынка, дорожная карта, редакции и цены.
5. Следующие шаги.

На слайдах 14 и 15 экраны модулей сменяются сами, на модуль можно нажать.

## Печать в PDF

PDF актуальной версии доступен по кнопке «Скачать PDF». Презентацию можно распечатать через Cmd+P (Ctrl+P). Формат страницы – 1920×1080, фон печатается.

## Как устроено

Основная страница `index.html` собрана из рабочего HTML. Шрифты Montserrat и JetBrains Mono, картинки и логотипы лежат в каталоге `assets/`. Страница содержит `noindex`.
